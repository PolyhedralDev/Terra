# 0003. Сохранять пакеты upstream-классов

Дата: 2026-06-15
Статус: принято

## Контекст

Форк сохраняет значительную часть исходного кода Terra. Массовый rename
затруднил бы сравнение с upstream, перенос исправлений и проверку авторства.
Политика ownership определена в `/CONTRIBUTING.md`.

## Решение

Оставлять существующие классы в `com.dfsek.terra`, а новые классы форка
создавать в `org.nullnomads.worldgen` и его подпакетах.

## Рассмотренные альтернативы

- Перенести весь код под namespace NullNomads: отклонено из-за огромного diff и
  потери прозрачной связи с upstream.
- Оборачивать каждый upstream type новым fork-owned type: отклонено как лишний
  слой без продуктовой пользы.

## Последствия

Название Java package само по себе не определяет ownership. При изменении
upstream-файлов необходимо сохранять исходные headers и ближайшие licenses.
