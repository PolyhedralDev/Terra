# 0002. Поставлять один зафиксированный Overworld pack

Дата: 2026-06-15
Статус: принято

## Контекст

Генерация должна быть воспроизводимой и не зависеть от изменяемого GitHub
release. Исходные версии и политика обновления определены в `/UPSTREAM.md`.

## Решение

Хранить TerraOverworldConfig как Git submodule на commit
`7d5a5c8d1eea9dee83077e3746efda6c74e56888` и упаковывать только pack
`OVERWORLD` версии `2.0.0`.

## Рассмотренные альтернативы

- Скачивать `latest` во время сборки: отклонено как невоспроизводимое.
- Поставлять несколько packs или metapack loader: отклонено как выход за рамки
  продукта и источник неоднозначной конфигурации.

## Последствия

Сборка завершается ошибкой при отсутствующем submodule. Обновление pack требует
отдельного commit, проверки лицензии, changelog и generation tests.
